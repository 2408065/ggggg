# Crafts by Mukesh

A simple, responsive showcase website for a handmade craft brand. Built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and navigation
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and current year in footer

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub and Vercel
1. Create a new repository on GitHub named `crafts-by-mukesh`.
2. Open a terminal in this project folder and run:

   ```bash
   git init
   git add .
   git commit -m "Create Crafts by Mukesh website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/crafts-by-mukesh.git
   git push -u origin main
   ```

   Replace `YOUR-USERNAME` with your GitHub username. If Git asks, sign in to GitHub.
3. Sign in to Vercel and choose **Add New → Project**.
4. Import the `crafts-by-mukesh` GitHub repository.
5. For this plain HTML/CSS/JS site, use the default/Other framework setting and leave build command and output directory empty if Vercel allows it. No build step is required.
6. Click **Deploy**. Vercel will provide a public URL.
7. For future updates, edit the files, then run:

   ```bash
   git add .
   git commit -m "Update craft website"
   git push
   ```

   Vercel automatically creates a new deployment when changes are pushed to the connected branch.

## Before publishing
Replace the sample email address in `index.html` with Mukesh's real contact address and update the sample product categories with actual products and photos.
